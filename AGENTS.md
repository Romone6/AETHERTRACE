# AETHERTRACE contributor instructions

Keep changes small and scientifically traceable. Never label synthetic fixtures as NASA data. Preserve source identifiers, release names, timestamps, wavelengths, masks, uncertainty and processing provenance wherever available. Do not infer astrophysical change from raw pixel subtraction alone. Validate and document all data crossing API boundaries. Keep shared API contracts coordinated through the main branch. Each workstream commits only on its assigned branch; the coordinator reviews and integrates changes.
