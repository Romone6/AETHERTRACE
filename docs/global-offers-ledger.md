# Global Offers for AETHERTRACE

Reviewed November 15, 2026 using the participant offer text supplied by the project owner and public provider documentation. The [official Space Apps event page](https://www.spaceappschallenge.org/2026/) lists GoDaddy, Google, Meteomatics, Microsoft, and Miro as Global Collaborators. The participant text supplies the product names, redemption instructions, and event-specific limits. No offer has been activated.

| Offer | Relevance to AETHERTRACE |

A trial-hosted demo stops when the trial ends or the credit runs out unless its billing account is upgraded. ## Release decision

Use the existing, rehearsed Vercel configuration for the submission URL if account access is available. Google Cloud Run is the cloud offer with the longer trial if the project needs a different host. A first-year domain has portfolio value once the public demo works.

For archive resilience, IRSA documents an anonymous AWS S3 mirror for SPHEREx DR1 source FITS products. That permits a future cache or batch pre-render of verified exposures. IRSA's cutout service and the mirror have different roles. The mirror carries FITS files, and an app running its own cutouts would have to preserve the pixel grid, wavelength WCS, flags, variance, and other required extensions. [IRSA cloud access](https://irsa.ipac.caltech.edu/cloud_access/) · [SPHEREx data access and cutouts](https://irsa.ipac.caltech.edu/spherex-archive-documentation/spherex-data-access/)
